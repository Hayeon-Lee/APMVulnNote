# APMVulnNote

Apache, PHP, MySQL 로 만든 모의해킹 실습용 게시판 웹 사이트입니다.

### 0. 기술 스택

- server: Apache 2.4, PHP 8.X
- DB: MySQL 8.x (phpMyAdmin 선택)
- UI: Bootstrap 5 (CDN)

### 1. 사용자 기능

- 회원가입/로그인/로그아웃
- 프로필 보기/수정(닉네임·소개·아바타)
- 게시판: 목록/검색/정렬, 글 작성·수정·삭제, 조회수
- 댓글: 작성/삭제(단일 뎁스)
- 파일 업로드: 게시글 첨부(1~3개), 다운로드

### 2. 관리자 기능

- 사용자 관리(권한 변경: user/admin)
- 게시글/댓글 관리(일괄 삭제)
